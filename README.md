# @nouisi/orb

`<noui-orb>` is the living form of the orange o in the noui mark: a voice surface, a loading and processing indicator, and the place assembled interface comes from. A framework-free Web Component.

**Status: work in progress, not yet published.**

Demo (once deployed): https://noui.si/lab/orb/
